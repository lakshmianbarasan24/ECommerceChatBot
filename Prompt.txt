Use:
FastAPI for the API
Gemini models/gemini- embedding-001 for embeddings Gemini gemini-2.5-flash for generating answers
FAISS for vector search
RecursiveCharacterTextSplitter for chunking

rag_pipeline.py
Implement a RAGPipeline class that: 
Reads knowledge.txt
Splits it using RecursiveCharacterTextSplitter
Uses Gemini embeddings to embed the chunks
Creates a FAISS IndexFlatL2 index
Saves the index to data/faiss/index.faiss
Saves chunks to data/faiss/chunks.txt
Loads an existing FAISS index 
Searches the top 3 relevant chunks for a question
Use:
chunk_size = 500
chunk_overlap = 100
top_k = 3
Also include a test section that builds
the index and searches:
How long do I have to return a product?
main.py
Create a FastAPI application with:
GET /
POST /ask
The /ask endpoint should:
Receive a customer question 
Search FAISS using the RAG pipeline
Get the top 3 relevant chunks 
Send the question and retrieved context to Gemini gemini-2.5- flash
Generate the final answer
Return:
{
"question": "...",
"answer": "...",
"retrieved_context":[...]
}
The Gemini prompt must tell the model to answer only from the retrieved context and say:
I don't have enough
information to answer that question.
when the answer is not available in the
context.
